# Getting help

| I want to... | Go to |
|---|---|
| Ask a question or get help using DevCouncil | [GitHub Discussions](https://github.com/bharathvbcr/DevCouncil/discussions) |
| Report a bug | [Bug report form](https://github.com/bharathvbcr/DevCouncil/issues/new?template=bug_report.yml) |
| Propose a feature | [Feature request form](https://github.com/bharathvbcr/DevCouncil/issues/new?template=feature_request.yml) |
| Report a security vulnerability | [Private advisory](https://github.com/bharathvbcr/DevCouncil/security/advisories/new), as described in [SECURITY.md](SECURITY.md). Never a public issue. |
| Report a Code of Conduct problem | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Contribute a change | [CONTRIBUTING.md](CONTRIBUTING.md) |

Before asking, the [documentation index](docs/README.md), the
[quickstart](docs/quickstart.md) and [project status](docs/project-status.md)
(limitations and retired commands) answer most questions.

When you report a problem, include the output of `devmap --version` (or the
version of the binary you ran) and the platform you ran it on. For DevMap
questions, `devmap status --json` says whether the index is fresh and complete.

DevCouncil is maintained by one person. Responses are best effort, with no
guaranteed turnaround.
