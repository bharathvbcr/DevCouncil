Query the knowledge graph

Usage:
  gortex query [command]

Available Commands:
  callers         Show who calls a function
  calls           Show what a function calls
  dependents      Show blast radius for a symbol
  deps            Show dependencies of a symbol
  implementations Show implementations of an interface
  stats           Show graph statistics
  symbol          Find symbols matching name
  usages          Show all usages of a symbol

Flags:
      --depth int       traversal depth (default 3)
      --format string   output format: text|json (traversal queries also support dot|mermaid) (default "text")
  -h, --help            help for query
      --index string    repository path the daemon must track (default ".")
      --limit int       max nodes in result (default 50)

Global Flags:
      --config string      config file (default .gortex.yaml)
      --log-level string   log level: debug|info|warn|error (default "info")
      --no-progress        disable animated progress output (also honored: NO_COLOR, TERM=dumb, CI, non-TTY stderr)

Use "gortex query [command] --help" for more information about a command.
