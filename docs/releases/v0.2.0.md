# DevCouncil v0.2.0 Release Notes

DevCouncil v0.2.0 establishes the high-performance native orchestration and code intelligence platform, transitioning from legacy runtime wrappers to compiled native binaries: a Go orchestrator host (`devcouncil` / `dev`) paired with Rust analysis and verification crates (`dcstore`, `dcverify`, `dcgrep`, and `devmap`).

## Highlights

### 1. Go Orchestrator Host (`devcouncil` / `dev`)
- **Native Go Host**: Replaces legacy Python orchestrator entry points with a single, fast native binary supporting both `devcouncil` and `dev` invocations.
- **MCP Server**: Integrated `devcouncil mcp` / `devcouncil mcp-server` stdio server exposing task verification, leasing, diff inspection, and policy write gates.
- **Multi-Host Integration**: `devcouncil integrate HOST` for Cursor, Claude Code, Codex, Gemini, OpenCode, Warp, Antigravity, and Aider.
- **Skills Distribution**: `devcouncil skills scaffold` and `devcouncil skills list` delivering agent skills directly into projects.

### 2. Rust Analysis & Verification Suite
- **`dcstore`**: Fast task repository and lease management with mutual exclusion SQLite index verification for safe concurrent agent building.
- **`dcverify`**: Deterministic verification engine executing unified-diff parsing, scope classification, rigor gates, anti-laziness checks, and test coverage evaluation.
- **`dcgrep`**: Ripgrep-powered search with ignore-rule awareness and optional trigram index support (`tgrep-core`).
- **`devmap` (v0.1.1)**: High-speed code graph intelligence engine featuring tree-sitter extractors for 36+ languages, store schema 20, and code graph schema 2.

### 3. Evidence Bundles & Gap Analysis
- Rich evidence bundles tracking task outcomes, agent interventions, and symbol locators.
- Deterministic feedback loop providing typed `next_actions` to guide agent self-repair during verification failures.

### 4. Installation & Environment Verification
- **Unified Installer**: `scripts/install.sh` builds and ad-hoc signs the Go host binary, links `~/.local/bin/dev`, and builds release binaries for `dcstore`, `dcverify`, `dcgrep`, and `devmap` via `scripts/install-components.sh`.
- **Automatic PATH & Shadow Detection**: Confirms all components resolve cleanly from `~/.local/bin`.
- **Apple Silicon & Host Sizing**: Built-in Ollama / local model size recommendations based on host RAM/VRAM.

## Verification Commands
