# DevCouncil v0.2.0 Release Notes

DevCouncil v0.2.0 and DevMap v0.2.0 are the same product version. The npm package,
the Go host (`devcouncil` / `dev`), and the Rust workspace (`devmap`, `dcstore`,
`dcverify`, `dcgrep`) all report **0.2.0**.

This release establishes the native orchestration and code intelligence platform:
a Go orchestrator host paired with Rust analysis and verification crates.

## Highlights

### 1. Go Orchestrator Host (`devcouncil` / `dev`)
- **Native Go Host**: Replaces legacy Python orchestrator entry points with a single, fast native binary supporting both `devcouncil` and `dev` invocations.
- **MCP Server**: Integrated `devcouncil mcp` / `devcouncil mcp-server` stdio server exposing task verification, leasing, diff inspection, and policy write gates.
- **Multi-Host Integration**: `devcouncil integrate HOST` for Cursor, Claude Code, Codex, Gemini, OpenCode, Warp, Antigravity, and Aider.
- **Skills Distribution**: `devcouncil skills scaffold` and `devcouncil skills list` delivering agent skills directly into projects.

### 2. Rust Analysis & Verification Suite
- **`dcstore`**: Fast task repository and lease management with mutual exclusion SQLite index verification for safe concurrent agent building.
- **`dcverify`**: Deterministic verification engine executing unified-diff parsing, scope classification, rigor gates, anti-laziness checks, and test coverage evaluation. `rigor::redact_secrets` remains the public helper GitPulse uses so ledger writes share `SECRET_PATTERNS` with the secret gate.
- **`dcgrep`**: Ripgrep-powered search with ignore-rule awareness and optional trigram index support (`tgrep-core`).
- **`devmap`**: High-speed code graph intelligence engine featuring tree-sitter extractors for 36+ languages, store schema 20, and code graph schema 2.

The analysis crates live in `rust/` (not `rust-port/crates/`). Install, GitPulse vendoring, and Manvi's sibling symlinks all read that one workspace. MCP answers stay scoped to the repository named on the request.

### 3. Evidence Bundles & Gap Analysis
- Rich evidence bundles tracking task outcomes, agent interventions, and symbol locators.
- Deterministic feedback loop providing typed `next_actions` to guide agent self-repair during verification failures.

### 4. Installation & Environment Verification
- **Unified Installer**: `scripts/install.sh` builds and ad-hoc signs the Go host binary, links `~/.local/bin/dev`, and builds release binaries for `dcstore`, `dcverify`, `dcgrep`, and `devmap` via `scripts/install-components.sh`.
- **Automatic PATH & Shadow Detection**: Confirms all components resolve cleanly from `~/.local/bin`.
- **Apple Silicon & Host Sizing**: Built-in Ollama / local model size recommendations based on host RAM/VRAM.

## Verification Commands

```bash
# Verify host binary
devcouncil --version   # devcouncil 0.2.0
dev --help

# Verify analysis components
dcverify health
dcstore --db .devcouncil/state.sqlite health
dcgrep health
devmap --version       # 0.2.0 (store schema 20, code graph schema 2, …)
```

## GitHub Release vs npm

This GitHub Release is the native Go host and Rust `devmap` archives.
Install those with `scripts/install.sh` (or the archives attached here).

npm `devcouncil@0.2.0` is the earlier Python-era package and **cannot be
overwritten**. This tag does not republish it. The npm `latest` dist-tag
remains the last Python-era 0.4.x until a new, unpublished version is cut.
The npm package at any version is a JS shim that execs the Go `devcouncil`
binary; it is not a substitute for the archives on this release.
