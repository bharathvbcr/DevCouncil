# DevCouncil v0.2.5 Release Notes

DevCouncil v0.2.5 and DevMap v0.2.5 are the same product version. The npm package,
the Go host (`devcouncil` / `dev`), and the Rust workspace (`devmap`, `dcstore`,
`dcverify`, `dcgrep`) all report **0.2.5**.

The last release published to GitHub is **v0.2.3**. **v0.2.4 was never published.**
Its notes stay in [v0.2.4.md](v0.2.4.md) so the release line has a step, and this
release is that draft plus the commits after the local tag `v0.2.4` (`6b889fd7`).
Do not push the `v0.2.4` tag. Anyone upgrading from v0.2.3 gets both.

## Included from unpublished v0.2.4

Carried forward from `docs/releases/v0.2.4.md` (the draft itself records the
detail, including the withdrawn mistaken stamp 1.3.5):

- An opt-in language-server pass on the resolver, a plain-language `ask` query,
  a per-file `skeleton`, and owners and test signal on `devmap blast`.
- Store schema **27**, extraction schema **89** at the 2026-10-11 draft, and
  workbench schema **13**.
- Route views over MCP, receiver typing, a policy ladder that judges every
  clause, `dc-redact`, and a verifier that never reports an unrun check as
  verified.
- A store that refuses trigger-carrying databases.

## Since local tag v0.2.4

109 non-merge commits, `6b889fd7..HEAD`. Grouped from those commits.

### Fixes

- The reference ladder reads the call ladder's import evidence for every
  family, and a field's declared type is keyed by its owning class on read.
- Secret paths now include `.aws/credentials`, `.envrc`, `.git-credentials`,
  and `*.p12`. A block-list gates value or a dangling config symlink fails
  closed. JSON operands handed to an unmodelled program are opened.
- Swift receivers are typed from the file's own text, and the resolver abstains
  where the file's scoping says the name means something else. Extraction
  schema moves to **90** (`fix(swift): abstain where the file's scoping…`).
- Rust blanket-impl methods bind at HIGH, not deterministic (`ft-f9665721`).
- Query reads (`graph core`, `ask`, clones, dead, route scan) stop on cancel.
  A backslash name is refused on Unix instead of being folded. Windows refuses
  backslash and control names.
- Budget-refused files are retried serially, and status names the files still
  refused. Notebook budget refusals are stamped in the build JSON.
- The watcher and freshness readers key names through `repo_relative_key`, and
  a moved repo-local store is rebound.
- Analysis-plane CI fails when the flag and state-dir contracts skip
  (`ft-2b9adeb0`).
- An unmet absolute accuracy floor is an open gate on a first measurement.
- The Codex MCP merge keeps comments and keys the user added inside
  `[mcp_servers.devmap]`.

### Changed

- Eight never-used `dc-store` tables are dropped on open, without a schema bump
  (`230e4ffc`; `rust/dc-store/src/schema.rs:601`).
- Kotlin is delisted from `CONFIDENT_TIER_ELIGIBLE`. Swift was re-measured on
  DevType and ChronosFlow (`ft-8ca270ad`), including deinit and extension rows.
- The accuracy record writes hashed labelled rows from one shared identity,
  and a row with unmeasured dead rows is not `CONFIDENT_TIER_ELIGIBLE` proof.

### Build and daemon

- **`devmap build` stops on Ctrl-C** (`5044ed56`, merge `7787808c`). One
  cancellation token runs from SIGINT into extraction and the serial
  budget-refusal retry. The first Ctrl-C makes the build return at its next
  file without committing a generation, and the process exits **130**
  (`rust/devmap-cli/src/interrupt.rs:22`, `main.rs:404`). A second Ctrl-C, or
  any Ctrl-C after extraction has finished and the build is persisting, exits 130
  at once rather than being acknowledged and ignored. The daemon trips the same
  flag from shutdown and from SIGTERM/SIGINT arriving mid-drain. Files refused by
  a cap are counted as cap-refused, never as cancelled.
- `devmap build --full` re-parses every source and writes a full generation;
  `--verify-rows` is its cheap half (it re-derives stored edge validity but keeps
  incremental extraction); `--force` is unrelated to both: it needs `--manifest`
  and replaces a foreign repo map or code graph (`commands/build.rs:35-80`).
- Every relative root is anchored and lexically cleaned once at the CLI boundary
  (`9cbd0f2b`). Budget refusals are named in `dead`, `affected` and `explore`
  caveats (`416c7ee1`), and an unreadable blast basis is unavailable content, not
  a mismatch (`a49c42bf`). Daemon status joins the analysis reason (`8bd6d4a1`).

### Dead-code and resolver precision

- A script's `ScriptEntry` claim spares its callables but no longer its
  module-level variables, for Python, JavaScript and TypeScript (`98598d70`,
  `5f9de533`; `liveness.rs`, `script_entry_exempts_callables`). Callables stay
  spared by scope decision, not proof. See DIVERGENCES X63.
- An unreferenced, unexported TypeScript/JavaScript `namespace` or `module` is
  published at 0.4 with reason `NAMESPACE_READ_UNEXTRACTED`, never in the
  confident tier, until extract-v98 (`dd0dac71`). See DIVERGENCES X64.
- Overloads that share one id never self-edge, and identical hits are one target
  (`c928b356`). This holds for same-file overloads only; a wider cross-file bundle
  was cut back (`8ed46bbe`). See DIVERGENCES X65.
- Path directories are keyed on either `/` or `\` in the liveness Go-package key
  and in `Resolver::parent_dir` (`98598d70`, `7a332cee`). See DIVERGENCES X66.
- Python: relative imports resolve in the importing package only (`ec034f60`);
  call-result receivers, owner-file field annotations and three-segment module
  paths, abstaining on shadows, ambiguous imports and opaque decorators
  (`e53d1665`); heritage residue (`79c721f5`). Swift: private nested namesakes,
  `-> Self` and generic-return chains, no bare-name dispatch from a chain
  (`55647cb1`). Go: a same-file type mention is a use, and a scoped reference reads
  only its own qualifier slot (`e01e6f0d`, `732f5311`).
- The headline resolution rate excludes call-blind and vendored code and carries
  its own denominators (`7e110127`). A rust-analyzer oracle labels the Rust half
  of the corpus record (`1c4866d2`), which now holds 21 corpora. A missed name in
  `search` names the parse hole that may hide it (`b539a1e9`).
