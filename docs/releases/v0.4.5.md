# DevCouncil v0.4.5 and DevMap v0.1.1

This local release merges the DevMap host artifact module, including bounded
artifact reads, read-only embedding, HTML controls, and host compatibility tests.
The DevMap workspace moves to 0.1.1 and aligns its SQLite dependency with MANVI
and GitPulse so the libraries can link into one application. The Python package
moves to 0.4.5 and retains a boolean result for artifact identity checks.

Python queries and manifest generation now resolve the same store as the
kernel, including repositories using the standalone `.devmap` directory.
An explicit store override remains authoritative.

DevMap remains available through its CLI and GitPulse MCP code-intelligence
operations. Repository guidance must name those operations explicitly; the guide
writer preserves files it does not own, including GitNexus-generated guides.
