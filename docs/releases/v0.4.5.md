# DevCouncil v0.4.5 and DevMap v0.1.1

These numbers were later unified to **v0.2.0**. See `docs/releases/v0.2.0.md`.

This local release merges the DevMap host artifact module, including bounded
artifact reads, read-only embedding, HTML controls, and host compatibility tests.
The DevMap workspace moves to 0.1.1 and aligns its SQLite dependency with MANVI
and GitPulse so the libraries can link into one application. The Python package
moves to 0.4.5 and retains a boolean result for artifact identity checks.

Python queries and manifest generation now resolve the same store as the
kernel, including repositories using the standalone `.devmap` directory.
An explicit store override remains authoritative.

DevMap remains available through its CLI and GitPulse MCP code-intelligence
operations. Repository guidance must name those operations explicitly; the guide
writer preserves files it does not own, including GitNexus-generated guides.

The final DevMap 0.1.1 build also includes the reliability fixes recorded in
`docs/devmap/RELIABILITY_AUDIT_2026-09-08.md`: lexical bindings and complete symbol
identities, source-verified freshness and snippets, bounded regular-file reads,
and stress checks that verify the restored generation.

The analysis crates now live in `rust/` rather than `rust-port/crates/`.
Install, GitPulse vendoring, and Manvi's sibling symlinks all read that one
workspace. MCP answers stay scoped to the repository named on the request.
`dc-verify::rigor` still exports `redact_secrets` and `contains_secret` so
GitPulse's ledger can redact vendor tokens through the same `SECRET_PATTERNS`
table the secret gate uses.

The companion `dcstore`, `dcverify` and `dcgrep` binaries are version 0.1.1.
`dcgrep` adds explicit, bounded tgrep indexes while preserving ripgrep matching
and live searches for changed or unindexed files. Index corruption and writer
contention produce visible fallbacks; rebuilding repairs corrupt cache pointers.
The component workspace passed 174 tests, formatting and strict Clippy on
macOS arm64. See `rust/README.md` for indexing and installation commands.

Consumers linking the DevMap libraries, including GitPulse's desktop and MCP
binaries, must rebuild to load these fixes. MANVI resolves the installed
`devmap` process; its existing 0.0.4 protocol supports the updated 0.1.1 kernel.
